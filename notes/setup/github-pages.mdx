这份命令属于 `ticoag.github.io` 的旧 MkDocs 站。当前这个仓库用 Mintlify：根目录执行 `mint dev`。

```sh
# 构建
mkdocs build

# 部署
mkdocs gh-deploy

# 测试本地预览
mkdocs serve
```
